## 🔑 Ключевые принципы

**1. Не восстанавливать — разворачивать заново**
Не пытайтесь «очистить» заражённую систему антивирусом. Единственный надёжный путь — чистая установка ОС и восстановление данных из проверенных резервных копий.

**2. Сначала изолировать, потом анализировать**
До начала любых работ отключите заражённые узлы от сети. Не выключайте — отсоедините кабель. Выключение может уничтожить криминалистические данные.

**3. Резервные копии — единственный источник данных**
Данные из зашифрованных файлов восстановить без ключа злоумышленника практически невозможно. Работайте только с тем, что есть в бэкапах.

**4. Восстанавливать в правильном порядке**
`Сеть → DNS/AD → Файловый сервер → Бизнес-приложения → Рабочие места`
Нарушение порядка увеличивает время восстановления в 2–3 раза.

**5. Закрыть вектор атаки до запуска**
Прежде чем включать восстановленную инфраструктуру, найдите и устраните точку входа. Иначе атака повторится.
