# ✅ Чеклист проверки перед запуском восстановленной инфраструктуры

> Выполняется **после** восстановления всех систем, **до** подключения пользователей.  
> Цель – убедиться, что инфраструктура чистая, работоспособная и защищённая.

**Дата проверки:** `_______________`  
**Выполняет:** `_______________`

---

## 1. Сетевая безопасность

- [ ] Все заражённые сегменты сети полностью изолированы или перестроены
- [ ] Смена всех паролей сетевого оборудования (маршрутизаторы, коммутаторы, точки доступа)
- [ ] Закрыт внешний RDP (порт 3389) или переведён на нестандартный порт + ограничен по IP
- [ ] Проверены правила файрвола – нет посторонних разрешающих правил
- [ ] Отключены неиспользуемые сервисы на периметре (UPnP, Telnet, устаревшие протоколы)
- [ ] VPN настроен с MFA или сертификатами
- [ ] DNS-сервер указывает на внутренние контроллеры домена, не на внешние

---

## 2. Active Directory

- [ ] Сброс паролей **всех** учётных записей домена без исключения
- [ ] Особое внимание: сброс паролей сервисных учётных записей (службы 1С, SQL, backup-агенты)
- [ ] Удалены или заблокированы неизвестные/посторонние учётные записи
- [ ] Проверены члены групп `Domain Admins`, `Enterprise Admins`, `Schema Admins` – только доверенные
- [ ] Проверены GPO – нет посторонних политик, добавленных атакующими
- [ ] Включён аудит входов (Event ID 4624, 4625, 4648)
- [ ] Настроена политика паролей: минимум 12 символов, сложность, история 10 паролей
- [ ] Включён и настроен LAPS (Local Administrator Password Solution)

---

## 3. Серверы и сервисы

### Файловый сервер
- [ ] Проверена структура прав доступа – соответствует исходной матрице доступа
- [ ] Нет папок с правами «Все: Полный доступ»
- [ ] Shadow Copies (теневые копии) включены и настроены

### Сервер 1С
- [ ] Тестовый вход в каждую информационную базу выполнен успешно
- [ ] Проверена актуальность данных в базах (последние документы, остатки)
- [ ] Права пользователей 1С соответствуют ролям
- [ ] SQL Server Agent запущен, задание резервного копирования БД активно

### Почтовый сервер
- [ ] Тестовая отправка и получение письма выполнены
- [ ] SPF, DKIM, DMARC настроены корректно
- [ ] Антиспам-фильтр активен

---

## 4. Антивирусная защита

- [ ] Антивирус установлен на **всех** серверах и рабочих местах
- [ ] Базы антивируса обновлены до актуальной версии
- [ ] Полное сканирование каждой восстановленной системы выполнено и завершено чисто
- [ ] Централизованная консоль управления антивирусом настроена
- [ ] Настроено оповещение администратора об угрозах

---

## 5. Резервное копирование

- [ ] Новый регламент резервного копирования утверждён и внедрён
- [ ] Первый бэкап восстановленной инфраструктуры создан и проверен
- [ ] Бэкап-сервер находится в **изолированном** сетевом сегменте
- [ ] Настроено копирование в облако или на внешний носитель (правило 3-2-1)
- [ ] Тестовое восстановление из нового бэкапа выполнено успешно
- [ ] Настроен мониторинг успешности задач резервного копирования

> Правило 3-2-1: **3** копии данных, на **2** разных типах носителей, **1** копия – вне офиса

---

## 6. Пользовательский уровень

- [ ] Все пользователи уведомлены о смене паролей
- [ ] Проведён инструктаж – [Инструкция для сотрудников](../templates/employee-instruction.md) выдана всем
- [ ] Пользователи не работают под локальными администраторами
- [ ] Настроен UAC на всех рабочих местах (не отключён)
- [ ] Тестовый вход каждого пользователя в корпоративные системы выполнен

---

## 7. Мониторинг и реагирование

- [ ] Настроен мониторинг критичных Event ID в Windows Event Log
- [ ] Настроены оповещения о множественных неудачных попытках входа
- [ ] Назначен ответственный за мониторинг безопасности
- [ ] Зафиксированы контакты для экстренного реагирования

---
